Sending Receipt PDFs on WhatsApp

Mortgage Management · proposal for the Lender · 10 November 2026

Today a Receipt opens in WhatsApp as a ready-typed message and the Lender presses Send. The ask: the same one click, but with the Receipt as a PDF reaching the Customer, without the paid WhatsApp Business API and without putting the Lender's number at risk.

✔ Lender still presses Send ✔ Free to run ✔ Official WhatsApp app only ✔ Windows laptop ✔ A handful a day ✔ A real PDF, not a picture

Options, best first

1

A link to the PDF, kept on the Lender's own Google Drive Recommended

Exactly today's flow. The message carries the Receipt text as now, plus a link that opens the PDF.

App makes the PDF → Saved to the Lender's Drive, private link → WhatsApp opens, text + link ready · Lender presses Send → Customer taps the link, the PDF opens
Lender does
One click, then Send. Same as today.
Customer gets
The Receipt text and a link that opens the PDF, which they can save.
Where the PDF lives
The Lender's own Google Drive, under an unguessable link, deleted after 30 days.
Risk to the number
None. Normal WhatsApp use.
Cost
Free. Drive's free space is far more than needed.
One-time setup
Sign in to Google once in the app's Settings.
Trade-off. The Customer receives a link, not a PDF bubble. WhatsApp cannot turn a link into a document; only the paid API can. A Receipt can be re-sent later, which simply makes a fresh file and link.
2

A small Windows helper puts the PDF straight into the chat Runner-up

The only route that delivers a real PDF document in the chat while nothing leaves the laptop.

Lender clicks Send PDF → Windows helper copies the PDF to the clipboard, opens the chat → Lender presses Ctrl+V then Enter → Customer receives a PDF document
Lender does
Click, paste, Enter. Windows asks "open this link?" the first time; tick "always".
Customer gets
A PDF document in the chat, with the Receipt text as its caption.
Where the PDF lives
Only on the laptop. Nothing is uploaded anywhere.
Risk to the number
None. It is the official WhatsApp app, used by hand.
Cost
Free.
Works on
Windows only, through the link Setup already registers.
To confirm first. That WhatsApp for Windows accepts a pasted PDF as a document. See the checks below. If the Lender values a true PDF in the chat over one fewer keypress, this option moves to first place.
3

The Windows Share panel Nothing to install

The browser hands the PDF to Windows, which lists WhatsApp among the apps to share with.

Lender clicks Share PDF → Windows Share panel opens → Lender picks WhatsApp, then the Customer → Lender presses Send
Lender does
Click, pick WhatsApp, pick the Customer, Send. Two picks the others avoid.
Customer gets
A PDF document. The Receipt text may not travel with it.
Where the PDF lives
Only on the laptop.
Risk to the number
None.
Cost
Free.
Works on
Windows, in Edge or Chrome.
To confirm first. That WhatsApp appears in the Windows Share panel on the Lender's laptop.
4

Download, then drag into WhatsApp Baseline

What is possible with the smallest change: a Download PDF button next to the message.

Lender clicks Download PDF → WhatsApp opens with the text · Lender drags the file in → Lender presses Send
Lender does
Click, find the file, drag it, Send. The most steps of any option.
Customer gets
A PDF document with the text as caption.

The laptop's Downloads folder.
Works on

Ruled out, and why

WhatsApp Business (Cloud) API. The only way to make a PDF arrive automatically. It needs Meta business verification, a number taken off the normal WhatsApp app, approved message templates, and in India now charges per message even for replies. Many approvals, not free.

Unofficial WhatsApp libraries. Fully automatic and free, but they break WhatsApp's terms and numbers do get banned. The Lender's number is the business; a ban cannot be undone.

Opening the laptop to the internet. Hosting the PDF from the laptop itself means it must be on when the Customer taps, and exposes the app beyond this laptop, which it was built never to do.

Two checks on the Lender's laptop, two minutes each

  1. Can WhatsApp take a pasted PDF? In File Explorer, right-click any PDF and Copy. Open a chat in WhatsApp, press Ctrl+V. If a document preview appears with a caption box, option 2 works.
  2. Is WhatsApp in the Share panel? In File Explorer, right-click any PDF and choose Share. If WhatsApp is listed among the apps, option 3 works.

Option 1 needs no check: it uses only what the app does today, plus Google Drive.

The decision

Go with option 1 if one click and today's familiar flow matter most, and a link that opens the PDF is acceptable for Customers.

Go with option 2 if the Receipt must land as a PDF document in the chat and every file must stay on the laptop, at the cost of Ctrl+V and Enter.

Either way the Receipt is the first document; whatever is built will carry any other PDF the app makes the same way. Nothing is built until this is approved.
