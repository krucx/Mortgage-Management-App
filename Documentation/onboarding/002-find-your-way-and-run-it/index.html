Chapter 002

Find your way and run it

The problem this chapter solves

You know the business now: Mortgages, Payments, Closures, the Lender's day. The next question every newcomer asks is practical. Where is everything, and how do I see it running? The repo has a backend, a frontend, Windows installers, a website, ADRs and a glossary, and the README is written first for the Lender, not for you.

Guessing costs more than time here. The obvious way to "just run it" opens the app on whatever database it finds, and on some clones that is a real lending book. This chapter gives you the map, and a safe way to run the app on the course's invented sample book, where every figure is one you've already met.

What you'll be able to do

  • Say which top-level folder a piece of work belongs in.
  • Find the file behind any screen or API route, by following its URL from App.tsx to main.py.
  • Look up a glossary term and its Avoid words, and find the ADR behind a rule.
  • Build and serve the sample book on scratch data, and check a figure on it.
  • Run both halves with hot reload on scratch data, and run the tests and type checks.

Before you start

Chapter 001, What the app does: the words and the cast. You need git, uv (it fetches Python 3.13 for you) and Node.js with npm. You don't need Docker.
