Developer onboarding

Mortgage Management, for new developers

Mortgage Management is the lending book of a single Lender who lends money against pledged gold jewellery. It runs on the Lender's own laptop and keeps track of who borrowed, against what, how interest grows, what has been paid, and how each pledge ended. This course takes you from never having seen the repo to making your first safe change in it.

How to use the course

  • Read the chapters in order. Each one assumes only the ones before it. A chapter takes about an hour.
  • Each lesson ends with a short quiz, and each chapter with a check-yourself page and a hands-on exercise. Answer before you look: recalling is what makes it stick.
  • Every example uses the same invented sample book, The Gold Chain Story's, on 19 Oct 2026. The cast sheet lists everyone in it.
  • The code is the source of truth. Each chapter records the commit it was written against; if the code has moved on, trust the code, and open an issue about the chapter.
  • Stuck? Ask an agent in this repo to explain anything that's unclear.
