The cast: the sample book on 19 Oct 2026

Every example in the course uses the same invented lending book: the one The Gold Chain Story tells. It is built by docs/sample-book/book.py through the app's own API, one dated change after another, and ends on 19 Oct 2026, the day the story is told. Nobody in it is real.

Serve it yourself

From backend/, into a fresh, empty scratch folder (002 · Lesson 4; every command is on the commands sheet):

export BOOK=$(mktemp -d)
uv run python ../docs/sample-book/book.py "$BOOK"
(cd ../frontend && npm install && npm run build)
uv run python ../docs/sample-book/serve.py "$BOOK"     # http://127.0.0.1:8765

The clock stays on 19 Oct 2026, so the figures below never move. The API gives amounts in paise (₹1 = 100 paise).
