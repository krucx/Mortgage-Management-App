Reference sheet

Routes

Every API route the course has taught so far: where its code lives, what it changes, its Preview twin, when it refuses, and the History Action it records. All paths start with /api. This sheet grows as chapters are written; so far it holds the routes one Payment uses (chapter 003) and the Closure routes (chapter 005).

Find a route by its path, not its folder. Every change that moves a Ledger, Payments included, is in lending/changes.py, not in payments/ (trap #1).
