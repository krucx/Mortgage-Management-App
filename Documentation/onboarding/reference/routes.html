Reference sheet

Routes

Every API route the course has taught so far: where its code lives, what it changes, its Preview twin, when it refuses, and the History Action it records. All paths start with /api. This sheet grows as chapters are written; so far it holds every save and Preview route for Mortgages and Payments (chapters 003, 005 and 006), and every Payment, Receipt and Cash Limit route (chapter 007).

Every change has the same shape (chapter 006): the save route opens engine.begin() and calls one change function in lending/changes.py, which refuses → writes → check_replays → records History. Its Preview route in lending/previews.py opens engine.connect(), runs the same function, reads before and after, and rolls back, so it is refused exactly when the save is (trap #5). 409 means the thing's state blocks the change; 422 means the request can't stand; FastAPI's own 422s (a list detail) come from the request model before any change runs.
Find a route by its path, not its folder. Every change that moves a Ledger, Payments included, is in lending/changes.py, not in payments/ (trap #1).
