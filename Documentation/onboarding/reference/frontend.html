Reference sheet

The frontend's data layer

How the screens ask the backend for anything: the hooks a page uses, the cache's keys, what each kind of change makes stale, and every read, list, Preview and change in frontend/src/requests.ts with the route it calls. Taught in chapter 011. Chapter 012 will add each page and the routes it calls.

The rules in one breath. Every request goes through the typed client, by a function in requests.ts; never fetch (trap #11). Change a backend model, run npm run gen:types and commit openapi.json and api.gen.ts (trap #10). Every key comes from keys in serverState.ts. A page saves through useLedgerChange, useMortgageChange or useChange(STALE_AFTER.…); what goes stale is declared there, not in the page.

The cache's keys

From keys in serverState.ts. A key is a path: making a prefix stale reaches every key under it.

KeyHoldsNested under it
['mortgage', id]a Mortgage (mortgageQuery)…, 'history'; …, 'projection', monthlyPayment
['customer', id]a Customer (customerQuery)…, 'history'
['customer', 'referrer', id], ['customer', 'search', q], ['customer', 'number-owner', phone]a Standalone Referrer; who matches a search; who owns a Primary Numberfiled under ['customer'] on purpose: a saved Customer changes them
['payment', id]a Payment and its Allocations…, 'receipt': its Receipt
['call-notes', mortgageId]a Mortgage's Call Notes
['list', name, filters, { page, sort }]one page of a list (useListPage); ['list', 'mortgages', 'every', filters] for everyMortgageQuery
['dashboard'], ['dormant']the Dashboard; the menu's Dormant count
['preview', …request.key]a Preview of a draft (usePreview); the draft is in the key
['outstanding-on-closure', id, on]the quote for closing a Mortgage on a date
['settings', group]a settings group (staleTime: Infinity)
['payment-methods'], ['update']the payment methods; whether a newer release is out (staleTime: Infinity)
['backups']the Backups' state; asked every second while one runs
['simulation', simulation], ['suggested-name', asked]a Simulation; the Mortgage Name the backend would givenever made stale: nothing is stored

What goes stale

"Asked now" means asked again at once if on screen; everything listed is marked stale either way, and the rest is asked when next shown.

ChangeSave throughAsked now, if on screenMarked only
Anything that can change what Mortgages owe: a Payment, a Void, a Mortgage edit, a Term Change added or removed, a Redemption, Waiver, Forfeit or Reopen, a new MortgageuseLedgerChange, or useMortgageChange if it returns the Mortgage['mortgage'], ['payment'], ['customer'], ['list'], ['dashboard'], ['dormant']['preview'], ['outstanding-on-closure']: the one on screen previews the change just made
A Notice approved, skipped or sentuseChange(STALE_AFTER.notice)['list', 'notices'], ['dashboard']
