Reference sheet

Commands

Every command a developer runs, with where to run it from. All of them work on scratch folders. None of them should ever be pointed at the repo's data/ or backups/, which may hold a real lending book. This sheet grows as chapters are written.

The one rule: any command that starts the backend gets a scratch DATA_DIR and BACKUP_DIR (or, for the sample book, a scratch folder of its own). Make one with mktemp -d.

Docker, your own code

Warned about in 002 · Lesson 5; taught in chapter 014. Not needed to develop.

FromCommandWhat it does
repo rootDATA_DIR="$DEV/data" BACKUP_DIR="$DEV/backups" APP_PORT=8081 docker compose -p mortgage-dev -f docker-compose.yml -f docker-compose.dev.yml up -d --buildBuilds and runs this folder's code on localhost:8081, on scratch data, under its own project name
repo rootDATA_DIR="$DEV/data" BACKUP_DIR="$DEV/backups" docker compose -p mortgage-dev -f docker-compose.yml -f docker-compose.dev.yml downStops it. The variables go on every docker compose command, or Compose reads .env.

Plain docker compose up -d runs the published images from Docker Hub, not your code, and reads DATA_DIR from .env. That's how the Lender runs it.
