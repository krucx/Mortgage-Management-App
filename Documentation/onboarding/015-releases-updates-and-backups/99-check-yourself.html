Chapter 015 · Check yourself

Can you ship it and keep a way back?

Try these from memory first. They mix release ordering, version checks, Backup files and database rollback.

Mixed questions

What must match the pushed version tag before artifacts publish?

The version job compares the tag with both package versions.

The running app is 3.9.0 and GitHub offers 3.10.0. Is that newer?

Each dot-separated component is converted to an integer before comparison.

What does a configured BACKUP_DIR contain after a normal Backup?

The Backup process snapshots SQLite, then adds photos if their folder exists.

A Backup uses the same minute as an existing one. What happens to its name?

_unused_name checks for an existing path and increments a suffix.

A migration changed the schema, and the new app then failed. What does Setup tell the Lender?

Old code may not read the new schema. Setup identifies the Backup; it does not restore it automatically.

Trace the dates

Predict: A Backup was made on 20 Apr at 10:30. The next daily run occurs on 26 Apr. Does it start a weekly Backup?

No. Only six days have passed. At seven days or more, the daily-run check starts one.

Predict: Current code is 3.4.0. The Lender presses Later for 3.4.1; then 3.4.2 is published. Does the banner appear again?

Yes. Later hides the version offered, while a higher version still appears.

Hands-on exercise: inspect an isolated Backup

Run the Backup tests. Each app uses scratch database and Backup folders.

cd backend
uv run pytest tests/test_backups.py -q

In tests/test_backups.py, change the expected first filename from mortgage-backup-2026-04-20-1030.zip to mortgage-backup-2026-04-20-1031.zip. Predict the failure, then run the command again. The fixed test clock makes the real Backup code keep producing 10:30, so the expected name no longer matches. Undo the exercise with git checkout -- tests/test_backups.py.

Recap

  • One tag gates two distributions; the image ships before the GitHub Release.
  • The backend checks releases daily; the banner hands Windows updates to Setup.
  • A Backup is a completed zip in BACKUP_DIR, with database and photos.
  • A migration can make old code unusable; restore the named pre-update Backup when needed.

For setup options and recovery steps, read README.md. For the storage decision, read ADR 0003.
