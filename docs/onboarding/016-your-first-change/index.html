Chapter 016

Your first change

The problem this part of the app solves

A Lender has set a Term Change for a future Accrual Date, then learns the date or rate should be different. Removing it and adding another works, but loses the connection between the original decision and its correction. This chapter makes one small change through the same layers a real feature uses.

You will add an edit for a coming Term Change, test it first, Preview the real change, record each changed field in History, and put the control in the Terms panel. The exercise uses a local branch and a served copy of the sample book.

What you'll be able to do

  • Turn an idea into a scoped issue using glossary words and the ADR test.
  • Write a backend change and API route test-first.
  • Add a Preview and a History Action with mutation checks.
  • Regenerate API types and connect a tested Terms panel.
  • Follow the repo's pull request, review, release and agent-skill workflow.

Before you start

Chapters 006, 011–013 and 015 cover change routes, frontend data, tests and releases. This is a capstone, so use those links when a layer needs a refresher.
