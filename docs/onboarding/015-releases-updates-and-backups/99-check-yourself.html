Chapter 015 · Check yourself

Can you ship it and bring the book back?

Work through these from memory. The questions mix the Backup, release, update, migration and restore steps.

Mixed questions

When does the weekly Backup check run?

There is no scheduler. The startup and daily-run paths start a Backup when one is at least seven days old.

Why can't an interrupted Backup appear as a finished archive?

The final filename appears only after a complete zip is safely copied into the configured folder.

Why might a Windows Backup be a plain zip?

A password requires the external zip program; without Docker it may be absent. With no password, Python writes the plain archive.

Which release details must agree before publication?

The workflow validates the version fields and extracts the matching release notes. The tag must be numeric x.y.z.

Why does a development build not show an update banner?

The dev configuration disables CHECK_FOR_UPDATES; test and sample apps inject no release lookup either.

What happens if a required before-update Backup fails?

The Backup callback runs before migration. If it raises, the schema remains unchanged and the app doesn't start.

Why does Setup not restore the pre-update Backup automatically?

ADR 0009 rejects an automatic restore because it would change the Lender's data without their decision.

Trace the versions

Predict: A Lender on 3.9.0 receives an available version of 3.10.0. Does the API consider it newer?

Yes. The comparison is numeric per component. The numeric comparison is pinned by test_versions_are_compared_by_number_not_as_text (#119).

Recap

  • A Backup, start to finish: a consistent database snapshot and photos become a complete zip.
  • Cutting a release: tests and matching versions gate the image and Windows zip.
  • How an update reaches the Lender: installed builds query once per day; Windows hands off to Setup.
  • When an update changes the database: code rollback cannot reverse a schema migration.
  • Bringing a Backup back: stop, replace database and photos, restart.

The release notes and restore steps are in CHANGELOG.md and docs/install.html.
