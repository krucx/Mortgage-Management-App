# Mortgage-Management-App

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on krucx/Mortgage-Management-App, using the `gh` CLI. See `Documentation/agents/issue-tracker.md`.

### Triage labels

Uses the five default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `Documentation/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` plus `Documentation/adr/`. See `Documentation/agents/domain.md`.
