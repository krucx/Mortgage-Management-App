# Mortgage-Management-App

## Agent skills

### Contribution and release workflow

Before changing code, follow [CONTRIBUTING.md](CONTRIBUTING.md): work on a branch,
open a pull request targeting `main`, respond to automated findings, and leave the merge
decision and approval to a human. For release work, follow the canonical
[release checklist](Documentation/RELEASE_CHECKLIST.md) and do not push a version tag
until a release owner has supplied and verified all required release inputs.

### Issue tracker

Issues are tracked in GitHub Issues on krucx/Mortgage-Management-App, using the `gh` CLI. See `Documentation/agents/issue-tracker.md`.

### Triage labels

Uses the five default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `Documentation/agents/triage-labels.md`.

### Domain docs

Single-context: one root `Documentation/GLOSSARY.md` plus `Documentation/adr/`. See `Documentation/agents/domain.md`.
